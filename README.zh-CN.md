# Auto Turn Off Bluetooth

**版本 1.2.0 · macOS 菜单栏应用 · 作者 catquickly**

[English](README.md)

这是一个仅面向 **MacBook 用户**的蓝牙控制工具，目的是提升个人隐私。它根据屏幕转轴角度，在合盖进入正常休眠前请求 macOS 完全关闭蓝牙电源；打开屏幕超过设定角度后，再开启蓝牙。

设计目标是让 MacBook 休眠时保持蓝牙关闭，减少向外发送蓝牙广播和信标。但**目前没有做无线射频或蓝牙信标检测，不能保证设备绝对不向外发送任何蓝牙信号**。应用只能确认 macOS 报告的蓝牙电源状态，不能测量无线发射；固件、查找功能和休眠行为可能因机型及系统版本而不同。请不要把它当成“绝对无线静默”的证明。

## 使用条件

- 需要带有兼容转轴角度传感器的 MacBook。
- 本次安装包仅支持 **Apple Silicon（arm64）**，系统最低要求为 macOS 14。
- **尚未测试 Intel 芯片 MacBook 的兼容性**，本次未提供 Intel 安装包。不面向台式 Mac。
- 蓝牙开关调用未公开的系统接口，未来 macOS 更新可能导致功能失效。

## 功能与默认设置

| 设置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 关闭蓝牙 | 转轴角度 ≤ 10° | 0°–60° |
| 开启蓝牙 | 转轴角度 > 130° | 70°–130° |

两个阈值之间保持当前蓝牙状态。默认规则下，正好 130° 不会触发开启。已保存的设置会保留，默认值仅适用于没有保存设置的安装。

- 菜单栏显示当前转轴角度。
- 菜单滑块分别调整关闭和开启角度。
- “登录时打开”使用 macOS 登录项服务。
- “后台常驻”使用独立 Launch Agent。启用并经系统批准后，退出菜单栏主程序，后台代理仍可检测；如要停止，请先关闭“后台常驻”，再退出主程序。
- 允许 Mac 正常休眠。真正休眠时普通应用与传感器轮询会暂停，因此关闭蓝牙需要在休眠前触发，不能理解成应用持续在睡眠中运行。
- 支持简体中文和英文，按系统首选语言显示。也可在“系统设置 > 通用 > 语言与地区 > 应用程序”中指定应用语言。
- 设置只保存在本机，无账号、统计分析或应用联网服务。

关闭蓝牙会断开蓝牙键鼠、耳机等配件，也可能中断隔空投送、接力等功能。测试时使用 MacBook 内置键盘和触控板。传感器可用性和合盖休眠的触发时机，需要在具体机型上确认。

## 安装与更新

1. 打开 `Auto Turn Off Bluetooth-1.2.0-arm64.dmg`。
2. 把左侧 **Auto Turn Off Bluetooth.app** 拖到右侧 **Applications**。
3. 更新时，先关闭旧版的“后台常驻”并退出旧版，再替换应用；随后从“应用程序”打开新版。
4. macOS 请求蓝牙权限时，按需允许。“登录时打开”和“后台常驻”可按需启用；系统可能要求在“通用 > 登录项”或“登录项与扩展”中批准。

制作或下载安装包不会替换正在运行的应用。新版本保持 `com.codex.hingebluetooth` 标识不变，沿用 1.1.0 的设置域和后台服务标识。

## 签名、未公证是什么意思

本次安装包使用**本机临时签名（ad-hoc）**。它会给程序和资源加上完整性校验，但不能证明作者是苹果认证的开发者；**本版本没有经过苹果公证**。签名校验通过，也不等于苹果做过恶意软件检查，或保证从网上下载后一定可以直接打开。

下载后首次打开可能出现系统提示。仅在确认来源可信、文件未被篡改的情况下，按苹果官方说明前往“系统设置 > 隐私与安全性 > 仍要打开”。不要全局关闭 Gatekeeper 或 SIP。[苹果操作说明](https://support.apple.com/zh-cn/102445)

要使用正式 Developer ID 签名并提交公证，需要作者的 Apple Developer 账号、证书和授权凭据。项目内不保存这些凭据；本次不会把临时签名称为正式开发者签名或已公证。

## 从源码构建

在 Apple Silicon Mac 安装 Xcode 命令行工具后，在项目目录执行：

```sh
./Scripts/build-and-package.sh
```

脚本会编译主程序和后台代理，复制两种语言资源，执行临时签名和校验，并在 `releases/` 生成带版本号的 DMG 及 SHA-256 校验文件。安装窗口布局需要 Finder 自动化权限。已有输出不会被直接覆盖；缓存和临时应用包保存在项目目录之外，构建结束后自动清理。

只生成本地 App、不制作 DMG：

```sh
./Scripts/build-and-package.sh --app-only /绝对路径/AutoTurnOffBluetooth.app
```

`Package.swift` 用于源码开发；生成完整应用包时请使用脚本，以便包含后台代理、登录配置和语言资源。
